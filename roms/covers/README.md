# Covers

Coloque aqui as imagens de capa/boxart dos jogos.

Como funciona:
- O RetroHub procura por imagens em `roms/covers/` (qualquer subpasta) com nomes parecidos com o nome da ROM.
- Formatos suportados: `.png`, `.jpg`, `.jpeg`, `.webp`.

Dica:
- Se quiser automatizar, use o script `npm run fetch:covers` (baixa boxarts de uma fonte publica na internet).
